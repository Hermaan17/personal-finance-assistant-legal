Privacy Policy

Personal Finance Assistant

Last updated: November 17, 2026

1. Introduction

Personal Finance Assistant is a personal financial management application designed to help its user record and manage personal income and expenses through a desktop application and WhatsApp integration.

This Privacy Policy explains what information is processed, how it is used, where it is stored, and how the user can request deletion of their information.

2. Information We Process

The application may process the following information:

  • WhatsApp phone number used to communicate with the application.
  • WhatsApp message identifiers (WAMID) used to identify messages and prevent duplicate transactions.
  • Text messages submitted for financial transaction recording.
  • Transaction amounts, income or expense types, categories, notes, and transaction dates.
  • Internal transaction identifiers and message processing statuses.

3. How Information Is Used

Information is processed for the following purposes:

  • To identify authorized WhatsApp message senders.
  • To interpret transaction information submitted by the user.
  • To record income and expenses in the financial database.
  • To prevent duplicate transaction recording.
  • To provide transaction confirmation messages through WhatsApp.
  • To maintain the functionality and security of the application.

4. Data Storage

Financial transaction records are stored in a local SQLite database on the computer running the desktop application. The default Windows storage location is the application's Keuangan data directory under the user's AppData folder.

The application stores transaction details and WhatsApp message identifiers, processing statuses, and related transaction identifiers. The original message body is used for processing and is not stored as a separate raw message body in the WhatsApp message record.

Database backups may also be created in the application's local backup directory.

5. Third-Party Services

The application integrates with Meta WhatsApp Cloud API to receive and send WhatsApp messages. Meta may process message information in accordance with its own terms and privacy policies.

Cloudflare Tunnel may be used to route incoming webhook requests to the computer running the application. Network requests may therefore be processed through Cloudflare infrastructure.

These services operate under their respective privacy policies and terms of service.

6. Data Sharing

The application does not sell personal information or financial transaction records.

Information may be processed by the third-party service providers described in this policy as necessary to operate WhatsApp messaging and webhook connectivity.

7. Data Security

The application uses webhook signature verification, authorized sender restrictions, and duplicate message detection to help protect its functionality.

Database security also depends on the security of the computer, operating system, user account, and any local backups.

8. Data Retention and Deletion

Transaction records remain in the local database until they are deleted by the user or the database is removed. WhatsApp message identifiers and processing records are also retained in the local database.

Users may request assistance with deleting their data by contacting the application administrator through the private communication channel used to operate the application.

See the Data Deletion Instructions page for further information.

9. Children's Privacy

This application is intended for personal financial management and is not designed to collect personal information from children.

10. Changes to This Policy

This Privacy Policy may be updated when application functionality, data processing practices, or applicable requirements change. The latest version will be published on this page.

11. Contact

For privacy questions or data-related requests, contact the application administrator through the private communication channel used to operate Personal Finance Assistant.
