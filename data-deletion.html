Data Deletion Instructions

Personal Finance Assistant

Last updated: November 17, 2026

1. About Data Deletion

Personal Finance Assistant is a personal financial management application that processes WhatsApp messages to record income and expenses.

Financial records and WhatsApp message processing records are stored in a local SQLite database on the computer running the application.

2. Data That Can Be Deleted

The application database may contain:

  • Personal income and expense transaction records.
  • Transaction amounts, categories, dates, and notes.
  • WhatsApp message identifiers (WAMID).
  • WhatsApp message processing statuses.
  • Links between WhatsApp messages and transaction records.
  • Account, category, and application user information.

3. How to Delete Locally Stored Data

The application user can delete all locally stored application data by following these steps:

  1. Close the Personal Finance Assistant desktop application.
  2. Stop the running WhatsApp webhook server and Cloudflare Tunnel.
  3. Open Windows File Explorer.
  4. Enter the following location in the address bar:
    %APPDATA%\Keuangan
  5. Delete the application data folder and its contents to remove the local database and stored backups.

The default database location is %APPDATA%\Keuangan\finance.db. Local backups are stored in the application's backups directory.

4. Alternative Data Locations

If the application is configured to use a custom data directory through the KEUANGAN_DATA_DIR environment variable, the user must delete the database and backups from that configured location instead.

If the application is running in portable mode, its data may be located in the application's data directory.

5. Important Information

Deleting the application data directory removes all financial records, user information, WhatsApp message processing records, and local backups stored there.

This operation is permanent unless an independent backup exists. Users should export any records they wish to retain before deleting the database.

Deleting locally stored application data does not automatically delete information retained by Meta or WhatsApp under their respective services and retention policies. Users should manage such information separately through the relevant services.

6. Confirmation of Deletion

After deleting the application data directory, the user can verify that the database file and local backup files are no longer present.

7. Contact

For questions about data deletion, contact the application administrator through the designated private communication channel used to operate Personal Finance Assistant.
